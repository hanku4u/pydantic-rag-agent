# Security Policy

## Passwords and keys

Passwords must be rotated every 90 days. Administrators must use hardware security
keys; password-only authentication is not permitted for administrative access.

## Access reviews

An access review is performed each quarter, and the results are filed with the
compliance team. Contractor accounts are reviewed monthly instead.

## Reporting a concern

Report suspected incidents to security@example.com. Do not use the public issue
tracker for anything that might be sensitive.
